# Ícones

Pixel art 12×12, multicolor, com contorno `#1a1c2c`. Use em 12, 24, 36 ou 48 px (múltiplos inteiros da grade) e nunca em tamanhos quebrados, que borram os pixels. Em código, prefira o componente `Icon name="…"`, que desenha o mesmo sprite.

- `moeda.svg` — Créditos (saldo gastável).
- `xp.svg` — XP (experiência, nunca reseta).
- `trofeu.svg` — Pontos de temporada e ranking.
- `tela.svg` — Tempo de computador.
- `camera.svg` — Registrar com foto / prova visual.
- `check.svg` — Aprovado / concluído.
- `ampulheta.svg` — Pendente de avaliação.
- `bau.svg` — Recompensa / Tesouro.
- `vassoura.svg` — Missões (tarefas da casa).
- `casa.svg` — Família / lar.
- `balde.svg` — Limpeza pesada, banheiro.
- `louca.svg` — Louça, cozinha.
- `d20.svg` — Sorteio balanceado.
